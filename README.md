# paiza 学習リポジトリ

paiza の問題を解きながら、データ構造とアルゴリズムを学習するリポジトリ。

- AI を使用せずにコーディングスキルをあげる
- データ構造とアルゴリズムは paizaA ランクくらいの複雑さで実務では十分
