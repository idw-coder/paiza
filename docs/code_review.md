## レビュー対象外

- `debug.log` への書き込みや、そのための `fs`、`logContent` などのデバッグ処理は意図的に残しているため、削除を勧める指摘は不要

## 以下の過去のレビューで良かったものを参考に

### 中間結果を全て作らずに済む方法がないか考える。

- 入力サイズが答えのサイズより桁違いに大きいとき、

例

- [...文字列、配列、イテレータ（s.matchAll()）など、、] もしくは Array.from() を書いたとき
- readFileSync を書いたとき
- await Promise.all(全件) を書いたとき

### 考慮漏れを防ぐために、フラグを作成したら以下を確認す

- フラグを true / false に切り替える条件が正しいか
- true / false それぞれで処理内容が正しいか
- true / false が切り替わった後、後続処理で正しいか

### ループ内の処理は、ループ外で行えるものがないかを考える

値が変わらない計算を毎回やり直しは無駄
TLE は Time Limit Exceeded の略で、実行時間制限超過の原因にも
